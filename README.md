# The World Today — Friday 20 November 2026

A newspaper front page summing up the world's news of Friday 20 November
2026, drawn pixel by pixel by a small Node program (`main.ts`, standard
library only, no network, deterministic). Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes `out/entry.png` (1024x1024 PNG, under 1 MiB). Two runs write
byte-identical files.

## How the image was made

`main.ts` draws the front page pixel by pixel: a hand-written 5x7 bitmap
typeface, hand-drawn pixel icons (globe, storm, charts, gavel, rocket, bat,
dove, water drop), and a hand-written PNG encoder (CRC32 + zlib via the
Node standard library). No network, no fonts, no image libraries — the
program is the whole artwork. Every fact in the image and in this file was
checked against news reports published on 20 November 2026.
